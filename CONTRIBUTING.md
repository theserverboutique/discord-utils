# Contributing

Thank you for your interest in contributing to Discord Utils!

We welcome bug reports, feature requests and improvements that help make this library more useful for the Discord.js community.

## Getting Started

1. Fork the repository.
2. Create a new branch for your changes.
3. Keep your code clean and consistent with the existing style.
4. Test your changes before submitting.
5. Open a Pull Request with a clear description of your changes.

## Reporting Bugs

When reporting a bug, please include:

- Node.js version
- Discord.js version
- Steps to reproduce
- Expected behaviour
- Actual behaviour
- Any relevant error messages

## Suggesting Features

Feature requests are always welcome.

Please explain:

- The problem you're trying to solve.
- Why the feature would be useful.
- An example of how it could be used.

## Code Style

Please aim to:

- Write readable, maintainable JavaScript.
- Keep functions focused on a single responsibility.
- Add documentation where appropriate.
- Follow the existing project structure.
- Test new functionality whenever possible.

## Questions

If you're unsure about anything, feel free to open an issue before starting work.

Thank you for helping improve Discord Utils!
