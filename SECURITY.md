# Security Policy

## Supported Versions

Security updates will be provided for the latest stable release of Discord Utils.

| Version | Supported |
|---------|:---------:|
| 1.x | ✅ |
| < 1.0 | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** create a public GitHub issue.

Instead, please contact the project maintainers privately with:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Any suggested fix (if available).

We aim to acknowledge security reports promptly and resolve confirmed issues as quickly as possible.

Thank you for helping keep Discord Utils secure.
