# Code of Conduct

## Our Commitment

The Server Boutique is committed to providing a welcoming, respectful and inclusive environment for everyone.

We encourage collaboration, constructive feedback and professional communication.

## Expected Behaviour

We ask all contributors to:

- Be respectful and considerate.
- Provide constructive feedback.
- Help create a positive learning environment.
- Respect differing opinions and experiences.
- Report unacceptable behaviour when necessary.

## Unacceptable Behaviour

Examples include:

- Harassment or discrimination.
- Personal attacks or insults.
- Trolling or intentionally disruptive behaviour.
- Publishing private information without permission.
- Any behaviour that would make others feel unwelcome.

## Enforcement

Project maintainers reserve the right to remove comments, issues or contributions that violate this Code of Conduct.

Serious or repeated violations may result in contributors being blocked from participating in the project.

## Contact

If you have concerns about behaviour within this project, please open a private discussion with the project maintainers.

Thank you for helping keep this project welcoming and professional.
